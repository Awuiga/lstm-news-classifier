# Проверка публикации

18 ноября 2026 года проверки выполнены отдельно от рабочего проекта.

- Локальные train/test CSV после нормализации CRLF → LF совпали с зафиксированным источником AG News. Хеши и условия использования приведены в `data/README.md`.
- Исходный `lstm_checkpoint.pt` загружен с `weights_only=True`; восстановленное стратифицированное разбиение с seed 42 дало 96 000 / 24 000 новостей. Полный словарь train точно совпал с сохранённым `stoi`.
- Сохранённая модель оценена на всей validation и официальном test: accuracy `0.905` / `0.901578947368421`, macro-F1 `0.9050569583174046` / `0.9016014160922428`. Переобучение и подбор настроек ради этих метрик не выполнялись. Оговорки об истории checkpoint/test находятся в README и JSON.
- Исходный `predict.py` выполнен с пользовательскими весами. Строка `Manchester United won the football match against Chelsea` классифицирована как `Sports`; максимальный softmax — `99.78517293930054%`. Это один демонстрационный пример, не оценка калибровки.
- Опубликованный `train.py` выполнен с нуля на небольшом искусственном CSV с четырьмя классами: одна эпоха, validation, сохранение лучших весов, оценка test и сохранение полного checkpoint. Затем эти новые веса успешно загружены в `predict.py`.
- Проверен режим `--epochs 0` с имеющимися весами и понятная ошибка при их отсутствии. Отрицательное число эпох отклоняется. Эти проверки не являются метриками на AG News.
- Проверены синтаксис, соответствие архитектуры и сохранение исходной логики. В копии `train.py` прежнее `epochs = 0` заменено аргументом командной строки с default 1 и проверкой значения; `predict.py` сохранён без изменения логики.
- Confusion matrix построена по опубликованному JSON и просмотрена. В отчёт не включены исходные тексты новостей.
- Хеши исходных скриптов, обоих файлов весов и CSV до и после подготовки совпали. Fashion CNN и GRU Text Generator не редактировались. В исходной папке LSTM Git-истории не было.

Окружение: Windows, Python 3.13.2, PyTorch 2.10.0+cu126, pandas 3.1.1, scikit-learn 1.9.1. CUDA доступна. Для графика использован Matplotlib 3.10.3.

Полное обучение на AG News заново не запускалось; реальные метрики получены оценкой готовых пользовательских весов. Установка зависимостей в чистое окружение и скачивание CSV с нуля отдельно не проверялись. В публичную копию не включены окружение, CSV, веса и рабочие логи.
